# 厚紙ロボット ― うでを動かそう

小学校のパソコンクラブ向けに作成した、マイクロビットとモーターを使う厚紙ロボットの教材です。A4・全3ページです。

[印刷用PDFを開く](pdf/厚紙ロボット_うでを動かそう.pdf)

1. 今日やること：角度とうでの位置
2. モーターの命令を使おう：拡張機能の追加と接続先の確認
3. うでをふってみよう：ブロックコードと自分のロボットの動きを考える課題
